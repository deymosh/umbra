## Key Dependencies

**Critical:**
- `net.zetetic:sqlcipher-android` 4.17.0 - Encrypted database (256-bit SQLCipher, 16 KB page size)

  - All local state persisted here; no second unencrypted database
- `com.squareup.okhttp3:okhttp` 5.4.0 - HTTP/WebSocket client (TOR-routed)
