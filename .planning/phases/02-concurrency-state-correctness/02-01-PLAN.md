## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User tap → RelayCrudCoordinator → Room relay table | Local user input (relay id, role flag) crosses into persisted relay configuration that drives which relays Umbra dials |
| Relay URL → isDmTransportAllowed | Relay URLs can originate from NIP-65 sync or auto-discovery, i.e. from remote authors, and are evaluated here for DM transport eligibility |

| T-02-01-01 | Tampering | `setDmEnabled` / `isDmTransportAllowed` | high | mitigate | The plaintext-`ws://`-non-onion rejection stays the first statement inside the mapper and is not weakened or reordered; only the dirty-flag assignment moves. Verified by the Task 1 test that a `ws://plain.example` relay is rejected and never persisted DM-active. |
| T-02-01-02 | Denial of Service | per-relay `Mutex` in `updateRelayRole` | medium | mitigate | The lock scope covers only the local read-map-persist plus two local repository side effects.
