# Phase 3 Citation Ledger

This is the citation ledger Plan 03-07 reads when writing each `docs/DONE.md` entry's
Evidence bullet. Each row names an existing test file, the exact backtick test method
name(s), and answers in writing whether that method would fail if only the entry's own
fix diff were reverted. A row that cannot answer that question is recorded `INSUFFICIENT`
rather than upgraded, and that entry stays in `docs/KNOWN_ISSUES.md`.

Columns: `LOG-N | Requirement | Verdict | Test file | Test method (exact) | Would fail if the fix were reverted, because | Run result`
