<objective>
D-03: Verify, for the 15 already-fixed entries that research identified as having existing test coverage, that a named test genuinely pins each fix — then record the exact citation for each in a single ledger file that Plan 03-07 consumes when it writes the permanent `docs/DONE.md` entries. This plan IS D-03's methodology in action: cite an existing test as evidence rather than writing a duplicate test for behavior already covered.

Purpose: The phase's second success criterion is that every automated-verifiable entry has a named, passing test that would have failed against the pre-fix code. Two of research's own pitfalls are that a plausibly-named test file often does not exercise the fix at all, and that a continue-on-failure test passes identically before and after a logging-only fix. This plan converts "research says a test exists" into "the method is named, was executed, and provably pins the fix".
Output: `.planning/phases/03-fix-validation-test-coverage/03-CITATIONS.md` — one row per entry with test file, exact method name, would-fail-if-reverted reasoning, and the run result.
</objective>
