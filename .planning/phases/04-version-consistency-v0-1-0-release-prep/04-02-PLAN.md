produce a standalone, dated record that this tree is actually ready to release.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub repository secrets → CI signing step → published artifact | The four signing secrets are the crown jewels of the release path. This plan reads their *names* to confirm the workflow is wired correctly; any path that surfaced a value would leak the app's signing identity permanently. |
| Local working tree → public repository | Everything written in this plan lands in tracked files that ship to a public GitHub repository. A keystore, a decoded secret, or a local key path recorded "for convenience" is disclosed the moment the branch is pushed. |
| Changelog → the public | The 0.1.0 entry is the claim this project makes to strangers about what is safe and working in a first public release. |
| Local git state → remote | Pushing a `v*` tag is the trigger that starts a real signed public release. This plan touches neither tags nor the remote. |
